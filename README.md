## Un bureau encombré ? Créez votre propre espace de travail.

Votre bureau Windows est rempli de dossiers, de fichiers et de raccourcis ?

**FolderDesk vous permet de créer un bureau indépendant pour chacun de vos projets**, sans machine virtuelle et sans bouleverser votre environnement Windows habituel.

Sélectionnez un dossier, ouvrez votre bureau de projet et retrouvez uniquement ce dont vous avez besoin pour travailler.

**Un projet. Un bureau. Zéro désordre.**

## Fonctionnalités principales

- **Un bureau par projet :** séparez vos différents espaces de travail.
- **Fichiers et dossiers :** accédez directement au contenu de chaque projet.
- **Applications :** ajoutez les raccourcis de vos logiciels installés.
- **Glisser-déposer :** organisez librement vos icônes.
- **Bureau Windows préservé :** retrouvez votre environnement habituel en quittant FolderDesk.
- **Léger :** aucune machine virtuelle nécessaire.
