# 🇫🇷 FolderDesk — Un bureau pour chaque projet

**FolderDesk est un logiciel Windows développé par GA Software pour organiser vos projets dans des bureaux de travail indépendants.**

Votre bureau Windows est encombré de fichiers, de dossiers et de raccourcis ? FolderDesk vous permet de créer un espace de travail propre pour chaque projet.

**Un projet. Un bureau. Zéro désordre.**

## ✨ Fonctionnalités

- Créer un bureau indépendant pour chaque projet.
- Ouvrir directement les fichiers d'un dossier de projet.
- Organiser les icônes, dossiers et raccourcis.
- Déplacer les icônes par glisser-déposer.
- Rechercher les applications installées et ajouter leurs raccourcis.
- Retrouver son bureau Windows habituel en quittant FolderDesk.
- Fonctionner sans machine virtuelle.
