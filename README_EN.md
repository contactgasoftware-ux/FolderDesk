# 🇬🇧 FolderDesk — One Desktop for Every Project

**Organize your Windows workspace with FolderDesk, developed by GA Software.**

## Overview

Is your Windows desktop cluttered with files, folders and shortcuts?

FolderDesk is a lightweight Windows application designed to create a dedicated desktop workspace for each of your projects.

Simply select a project folder and open a separate workspace containing the files, folders and application shortcuts you need.

When you close FolderDesk, your regular Windows desktop remains unchanged.

**One project. One desktop. Zero clutter.**

## ✨ Features

- Create a dedicated desktop for each project.
- Access the files and folders in your project directory.
- Organize desktop icons, folders and shortcuts.
- Move icons using drag and drop.
- Search installed Windows applications and add their shortcuts.
- Return to your regular Windows desktop when closing FolderDesk.
- Lightweight operation without virtual machines.
